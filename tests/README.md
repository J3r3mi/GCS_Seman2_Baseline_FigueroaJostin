# Pruebas del sistema

Este directorio está destinado a almacenar y organizar los elementos relacionados con las pruebas del Sistema de Gestión de Contactos Agenda.

## Objetivo

Las pruebas tienen como objetivo verificar el correcto funcionamiento de los principales componentes del sistema y comprobar que los requisitos definidos en el documento `SRS_v1.md` sean implementados correctamente.

## Tipos de pruebas

Se contempla inicialmente la realización de los siguientes tipos de pruebas:

- Pruebas unitarias para validar componentes individuales.
- Pruebas de integración para verificar la comunicación entre la aplicación cliente y la API REST.
- Pruebas de integración para validar la comunicación entre la API REST y la base de datos.
- Pruebas funcionales para comprobar el cumplimiento de los requisitos del sistema.

## Organización

Los casos y evidencias de prueba se incorporarán progresivamente conforme avance el desarrollo del sistema.

## Estado

Actualmente se mantiene una estructura inicial para la gestión de pruebas. Las pruebas detalladas serán incorporadas en futuras iteraciones del proyecto.
